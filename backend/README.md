# LawInc Backend API

FastAPI backend for the LawInc legal-information platform.

## Local development

From the `backend` directory:

```bash

uv run fastapi dev

```

## The local API is available at:

- **API Documentation**: [http://127.0.0.1:8000/docs] (http://127.0.0.1:8000/docs)

## Tests

```bash

uv run pytest

```
